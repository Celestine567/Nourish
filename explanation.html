HTML Structure

Early Wireframe Design

Before actually building the website, an early wireframe sketch was made to ensure concepts and goals are aligned.

Consistent Webpage Layout

The website maintains consistency across all pages through shared banner and footer components. This creates a cohesive user experience and clear navigation structure.

Content Organization

Each tutorial page follows a structured approach to present game information effectively.

Content Structure Pattern:

  • Overview sections - Introductory paragraphs explaining game concepts
  • Gallery articles - Visual presentation of game elements with descriptions
  • Card layouts - Individual character/item showcases with images and stats
  • Descriptive text formatting - Use of <strong> and <i> for emphasis

Semantic Containers

The HTML uses semantic elements like <main>, <section>, <article>, and <figure> to create meaningful document structure. This improves accessibility and SEO while making the code more maintainable.

Key Semantic Elements Used:

  • <main> – Contains the primary content of each page
  • <section> – Groups related content together (HTML, CSS, JavaScript sections)
  • <article> – Self-contained content pieces within sections
  • <figure> & <figcaption> – Images with descriptive captions

Navigation and Layout

The navigation bar within the <div class="banner"> provides intuitive links to each major section of the site. This enhances user experience by enabling easy access to relevant content such as gameplay instructions, plant and zombie guides, and quizzes.

Navigation Features:

  • Clickable Logo – Returns the user to the homepage for quick orientation
  • Hyperlinks – Clearly labeled and grouped for fast access to key topics
  • Responsive Flex Layout – Maintains accessibility and structure across devices

Multimedia Integration

Images and figures are embedded with appropriate <img> tags and <figcaption> elements to support visual learners and provide contextual meaning. Alt text ensures accessibility for screen readers.

Effective Use of Media:

  • Illustrative Screenshots – Help users visually understand gameplay and characters
  • Alt Attributes – Enhance accessibility for users with visual impairments
  • Figures with Captions – Improve semantic clarity and content relevance

CSS Styling

Single Shared CSS File

A single stylesheet is used to maintain consistency in design across all web pages. The CSS file is well-structured with clear comments separating general styling rules from page-specific sections.

Key Benefits:

  • Centralized styling ensures a unified look and feel.
  • Clear comments enhance readability and make future updates easier.
  • Reduces code duplication and improves site performance.

Use of Fonts

Typography plays a crucial role in creating a visually coherent and user-friendly interface. Carefully selected fonts are used to distinguish content types while maintaining harmony throughout the site.

Font Choices:

  • Galindo – A decorative font applied to major headings for personality and visual flair.
  • Sans-Serif – A clean, modern font used for body text to improve readability.
  • Consistent typography strengthens brand identity and page structure.
  • Limited font variety prevents visual clutter and maintains professionalism.

Use of Media and Images

Visual content is incorporated throughout the site to support understanding and increase engagement. Images serve both aesthetic and educational purposes, especially for new players unfamiliar with game elements.

Media Purposes:

  • Enhances comprehension by visually representing game mechanics and items.
  • Helps users identify plants, zombies, and gameplay scenarios.
  • Adds vibrancy to the pages, keeping them dynamic and inviting.
  • Improves overall user experience by reducing text-heavy content.

Enhanced User Interaction via Transitions and Hover Effects

Micro-interactions like transitions and hover effects provide immediate visual feedback, reinforcing the interactive nature of the UI. These animations make the experience smoother and more intuitive, guiding the user's attention and encouraging engagement.

Interactive Feedback Examples:

  • transition: transform 0.15s, border-radius 0.15s – Applies smooth animations when elements scale or change shape
  • .banner-flex a:hover – Highlights navigation links with hover styles such as shadows, underlines, or color shifts
  • aside img:hover – Slight zoom-in effect (transform: scale(1.1)) gives visual depth and indicates interactivity

Responsive Layouts with Flexbox & Media Queries

The site adapts seamlessly across devices using responsive design principles. Flexbox is the primary layout engine for both structural and component-level design, while media queries ensure content margins remain comfortable on narrow screens.

Responsive Techniques:

  • .banner-flex – Wraps navigation items into rows on small viewports
  • .card / .card1 – Uses display: flex with flex-wrap for dynamic gallery grids
  • @media (max-width: 82em) – Adjusts main margins for consistent padding across devices

Sticky Header Navigation

The header is pinned using modern positioning techniques, ensuring key navigation remains visible. This supports faster navigation and enhances the user experience, especially during long scroll sessions.

Sticky Techniques:

  • position: sticky – Keeps the header fixed at the top during scroll
  • top: 0 + z-index – Ensures layering above other elements
  • scroll-padding-top – Offsets anchor targets to prevent content from being hidden

Global Variables & Custom Properties

Custom properties centralize styling decisions, making the design scalable and easy to maintain. Updates to the theme can be made by adjusting a few global variables.

Key Custom Properties:

  • --banner-color / --accent-color – Control highlight elements for visual identity
  • --background-color / --article-background – Maintain strong contrast for readability
  • --aside-background / --aside-font-color – Create clear, consistent side content sections

Typography & Visual Hierarchy

A balanced typographic system supports readability and brand expression. Font weights, sizes, and spacing are adjusted to reflect importance and guide user attention across the page.

Typography Highlights:

  • h1 with Galindo font – Gives personality to titles with a custom font
  • h2–h5 scaling – Defines clear levels of visual hierarchy
  • line-height, spacing, and text shadows – Enhance legibility and structure

Transitions & Hover Interactions

Subtle transitions create a polished interface by providing responsive feedback. These effects improve user perception of speed and usability without being distracting.

Interactive Details:

  • .banner-flex a:hover – Highlights navigation links with shadows and color changes
  • img:hover – Adds gentle scale transform to emphasize interactivity
  • transition: 0.15s–0.3s – Ensures quick, consistent animations

JavaScript Functionality & Quiz Logic

State Management & DOM References

The script begins by defining key state variables and caching DOM elements for efficient access. This reduces repeated DOM queries and simplifies state updates.

Key Elements:

  • let slides, currentSlide = 0, isReviewMode – Track quiz slides, active slide index, and review mode flag
  • document.getElementById(...) – Cache references to quiz container and control buttons

Question Data Structure

Questions are stored in the quizQuestions array, with each question being an object containing all necessary information:

Supported Question Types:

  • MCQ: Multiple choice with radio buttons
  • Text: Free text input with case-insensitive matching
  • Number: Numeric input with exact matching
  • Date: Date picker input with exact matching

Quiz Generation: buildQuiz()

buildQuiz() dynamically constructs each question slide by iterating over quizQuestions. It handles multiple question types (MCQ, text, number, date) and injects HTML into the page.

Technique Highlights:

  • Array.forEach() – Loops through question objects
  • Template literals – Build HTML strings for slides and answers
  • InnerHTML assignment – Renders all slides at once, then collects them into slides

Slide Navigation: showSlide(), showNextSlide(), showPreviousSlide()

These functions manage which slide is visible by toggling the .active-slide class. Button visibility is updated based on the current slide and review mode.

Navigation Logic:

  • classList.add/remove() – Show or hide slides
  • Conditional style.display changes – Enable/disable navigation and action buttons
  • Guard clauses for first, last, and results slides

Answer Validation: compareAnswers()

This function abstracts answer checking for all question types. It normalizes text inputs, converts number strings, and compares dates exactly.

Validation Steps:

  • Read user input via querySelector (radio or text input)
  • Normalize and compare based on question.type (text, number, date)
  • Return an object with isCorrect and userAnswer

Scoring & Feedback: showResults()

Upon submission, the script tallies correct answers, prompts for unanswered questions, and displays a stylized results slide with an animated score and personalized message.

Result Workflow:

  • Count correct answers, collect unanswered indices
  • confirm() – Offer to revisit unanswered questions
  • Generate results HTML with dynamic score and message
  • Invoke showSlide() to display the final slide

Review Mode: checkAns()

Review mode locks inputs, highlights correct answers in green, and marks wrong answers in red. It also appends corrective hints for non-MCQ questions.

Review Mode Features:

  • Disable all inputs (inp.disabled = true)
  • Apply inline styles to labels/inputs based on correctness
  • Append correction notes for text, number, and date questions

Ending the Quiz: backToHome()

A confirmation dialog prevents accidental navigation away from the quiz.

User Safety Features:

  • Confirmation Dialog: Warns user they will lose current progress
  • Clear Navigation: Direct link back to homepage when confirmed
  • Non-destructive: Canceling the dialog maintains quiz state

Event Handling System

The quiz uses modern event listeners to handle user interactions:

// Navigation Events submitButton.addEventListener('click', showResults); previousButton.addEventListener("click", showPreviousSlide); nextButton.addEventListener("click", showNextSlide); backToHomeButton.addEventListener("click", backToHome); checkAnsButton.addEventListener("click", checkAns);

Each button has a specific role in the quiz flow, and the event listeners ensure proper function execution when users interact with the interface.

Button Interactions

Buttons control quiz flow and user interaction. Each button is assigned an id and tied to specific functions using addEventListener.

Button Functions:

  • #previous – Navigates to the previous question via showPreviousSlide()
  • #next – Advances to the next question with showNextSlide()
  • #submit – Submits all answers and shows results using showResults()
  • #checkAns – Triggers review mode using checkAns() to highlight correct and incorrect responses
  • #backToHome – Confirms and redirects to home page via backToHome()

String Interpolation: template literals

Template literals using backticks (`) and ${} enable dynamic HTML generation. They simplify insertion of variable values directly into strings.

Usage Examples:

  • Generate unique IDs: id="q${i}_${key}"
  • Conditional rendering: ${question.image ? ... : ''} for optional image display
  • Dynamic result summary: ${numCorrect}/${quizQuestions.length} in final feedback
  • Warning message for unanswered: ${questionNumbers} in a confirmation dialog

User Experience Features

Smart Navigation:

  • Context-Aware Buttons: Previous/Next buttons appear only when relevant
  • Submit Protection: Submit button only appears on last question
  • Review Navigation: Different button layout during review mode

Feedback System:

  • Immediate Visual Feedback: Colors and styling indicate correctness
  • Encouraging Messages: Personalized feedback based on performance
  • Progress Indication: Question numbers show quiz progress

Accessibility Considerations:

  • Proper Labels: All inputs have associated labels
  • Alt Text: Images include descriptive alt attributes
  • Keyboard Navigation: Tab order follows logical flow
  • Color + Text: Visual feedback includes both color and text
